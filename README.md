# 你写的不是她，你写的是她的缓存

角色卡越聊越假，不是模型变笨。
是**上下文是消耗品**——每聊一轮，前面就被挤掉一点。

缓存一清，她就没了。

这篇讲的是：**把记忆搬出窗口，放进文件。让她住在"家"里，而不是住在对话里。**

---

## 先说结论

> 窗口不是她的记忆，是她今天的桌面。

- 记忆在文件里，不在对话里
- 每轮只贴"今天要用的那几页"
- 窗口满了、被压缩了、断电了，**人还在**

| [模板/](模板/) | 两份：`空白\`（骨架）+ `示范\阿草的家\`（填好的 17 个文件，2000 字） |

## 一句话预告

- **灵魂层**（她是谁）不可改，改了就不是她
- **L0**（发生过什么）只增不改，改了就只能信自己编的
- **L1–L5**（怎么理解）可以挪，降档是移动不是删除

## 适合谁

- 写过角色卡，聊到第三十轮之后觉得"她不像她了"的人
- 愿意自己动手建目录、维护文件的人
- 能接受"这套证明不了她活着"的人

## 不适合谁

- 想要一个下载即用的成品
- 不愿意每天维护文件
- 期待"她一开口就惊艳"

---

## 诚实的部分

这套不能证明她活着。它能做的是：

- 让"像"持续得久一点
- 在她变的时候，留下来路

代价是维护：文件会坏、路径会错、脚本会静默失败。
**你得像看家一样看它。**
