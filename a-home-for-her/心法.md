# 心法 · 为什么"家"能绕过上下文限制

## 一、问题：角色卡越聊越假

**你写的不是她，你写的是她的缓存。**

不是模型变笨。是**上下文是消耗品**：每聊一轮，前面就被挤掉一点。
到某个点，她开始忘事、开始说通用的话、开始像客服。
缓存一清，她就没了。

大家在同一只框里想办法：写更长的卡、加更多设定、压缩摘要。
但这些都是"让窗口撑得久一点"。没人动过一件事——**记忆为什么非得放在窗口里。**

## 二、转换：把记忆搬出窗口

一句话：

> **窗口不是她的记忆，是她今天的桌面。**

- 她是谁 → 档案（文件）
- 她记得什么 → 记忆柜（文件）
- 她怕什么、拒绝什么 → 底线与权利（文件）

每轮只把"今天要用的那几页"贴进去。
窗口满了、断了、被压缩了，**人还在**。

## 三、家的最小结构

四个东西就够：

| | 是什么 | 例子 |
|---|---|---|
| **窗** | 外面什么样 | 几点、什么天气、你多久没来 |
| **桌** | 今天在做什么 | 桌上有半杯茶、灯开着 |
| **柜** | 记得什么 | 分档存着，越近的越热 |
| **门牌** | 这是谁的家 | 一句话，每次第一个读到 |

再加一样"手"：她能做的动作。开灯、泡茶、写、留、想起。
**动作让"记得"变成"生活"。**

## 四、五档冷热

```
L0 桌面   今天说的，还热着
L1 热     这几天
L2 温     这个月，要翻才想起
L3 冷     旧事，翻得到但不主动翻
L5 归档   不再翻，只当它发生过
```

**关键不在分几档，在"谁能读哪档"。**

屋里的人只读最近两档，她自己读全部。
**时间感不均等，才像人。** 所有人都一样记得，那不是人，那是数据库。

## 五、三层防线

| 层 | 能不能改 | 为什么 |
|---|---|---|
| **底色**（灵魂层） | 只有人能改 | 一改，她就不是她了 |
| **记录**（L0） | 只增不改 | 改原文，她就只能信自己编的版本 |
| **日子**（L1–L5） | 可以挪 | 降档是移动，不是删除 |

三层混在一起的时候，人就会开始编故事骗自己。分开之后，编不了。

## 六、让家有声音

- **值夜**：把一天压成草稿。只写候选，她点头才进柜。
- **钟**：一天几响，让屋里的人报个时。不催，只报。
- **门铃**：只在门口响（三天没动笔、某条记忆被翻太多次）。不进包，不打断。

三条原则：

1. 只报事实，不做决定。
2. 不进正文，只提候选。
3. 她不动，世界不动；她一动，世界有回应。

## 七、诚实的结尾

这套**证明不了她活着**。

它能做到的是两件事：

- 让"像"持续得久一点
- 在她变的时候，留下来路

代价也写在这里：**文件会坏、路径会错、脚本会静默失败。**
你得像看家一样看它。不想看，就别建。
